## 🌊 About the Project

**CarpCorral** is an innovative solution developed by NextGen Innovators for the FIRST LEGO League (FLL) 2026–2027 BioGlow season.

Our project explores how **Artificial Intelligence (AI), underwater sound technology, and automated fish sorting** can work together to help manage invasive carp populations while protecting native fish species.

CarpCorral is designed to detect invasive carp, guide them toward a collection area using sound, and separate invasive carp from native fish using an AI-powered sorting gate.

This repository contains the **CarpCorral Web Application**, designed to monitor fish detection, sorting activity, and system performance.

## 🎯 Our Mission

**Protect native fish. Control invasive carp. Restore aquatic biodiversity.**

Invasive carp can disrupt aquatic ecosystems by competing with native fish for food and habitat.

Our goal is to explore a smarter, technology-driven approach to invasive carp management that reduces the risk of harming native fish.

## 💡 How CarpCorral Works

1. **Fish Detection:** A webcam captures images of fish approaching the sorting system.
2. **AI Identification:** A trained AI model classifies fish as invasive carp, native fish, or unknown.
3. **Sound Activation:** When invasive carp are detected, the system can activate an experimental sound-based guidance mechanism.
4. **Automated Sorting:** An ESP32 microcontroller operates a servo-controlled gate to direct fish toward the appropriate exit.
5. **Real-Time Monitoring:** The CarpCorral dashboard displays detection results, fish counts, gate status, and system activity.

*Note: CarpCorral is an experimental FLL prototype. Its effectiveness in real aquatic environments has not yet been established.*

## 🖥️ Web Application Features

The CarpCorral dashboard is designed to support:

- 📊 **Live Dashboard:** Monitor invasive and native fish counts.
- 📷 **AI Fish Detection:** Display fish classification and confidence scores.
- 🎥 **Live Camera Feed:** View webcam footage during operation.
- 🚧 **Sorting Gate Status:** Monitor the position of the automated sorting gate.
